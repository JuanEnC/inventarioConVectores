#  Inventario con Vectores

Este proyecto es una aplicación web sencilla desarrollada con **HTML**, **CSS** y **JavaScript**, que permite gestionar un inventario utilizando **vectores (arreglos)** como estructura principal para almacenar los productos.

---

##  Funcionalidades

- Agregar productos al inventario  
- Eliminar productos  
- Buscar productos por código  
- Mostrar el listado completo del inventario
- Agregar un producto al inicio

---

##  Estructura del proyecto

```

/inventario
│
├── inventario.html        # Interfaz principal del inventario
├── inventario.js          # Lógica del sistema (manejo del arreglo de productos)
├── producto.js            # Clase o funciones relacionadas con productos
├── main.css               # Estilos básicos de la interfaz
└── README.md              # Documentación del proyecto

````

---

##  Tecnologías utilizadas

- **HTML5** → estructura de la página  
- **CSS3** → estilos simples y responsivos  
- **JavaScript (ES6)** → lógica del inventario y manipulación del DOM  

---

##  Cómo ejecutar el proyecto

1. Clona este repositorio:
```
   git clone https://github.com/JuanEnC/inventarioConVectores.git
```

2. Entra a la carpeta del proyecto:

 ```
   cd inventarioConVectores/inventario
   ```

3. Abre el archivo `inventario.html` en tu navegador.
   ¡Listo! Podrás interactuar con el inventario directamente desde la interfaz.

---

##  Ejemplo de uso

1. Escribe los datos del producto (nombre, código, cantidad, precio).
2. Presiona **Agregar** para incluirlo al inventario.
3. Usa las opciones para **buscar**, **eliminar** o **listar** todos los productos.
